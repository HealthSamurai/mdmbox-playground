# MDMbox Playground

A collection of examples that demonstrate the capabilities of [MDMbox](https://www.health-samurai.io/mdmbox).

The examples run MDMbox alongside Aidbox. Start the shared environment from the examples directory:

```bash
cd examples
docker compose up
```

See [examples/README.md](examples/README.md) for activation instructions and the list of examples.
